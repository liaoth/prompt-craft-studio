# 使用手册

[返回首页](../../README.md) · [快速开始](quick-start.md) · [配置手册](configuration.md)

## 工作台布局

- **左栏**：默认词库、我的常用词、搜索分类、场景模板。
- **中栏**：生成模式、中文创意、双语彩色词块、完整 Prompt、结构化编辑和图片助手。
- **右栏**：Midjourney 参数。
- **顶部/抽屉**：历史、作品库、服务配置和账号。

手机端使用分页和抽屉，功能与桌面端一致。

## 两种生成模式

### 结构规则

无需 AI Key。系统按固定结构、双语预设和当前参数稳定组装 Prompt，适合快速起稿和离线使用。

输入的中文创意不会被忽略：没有主体时进入主体，有主体时作为自定义补充。

### AI 三版本

需要用户 AI 或站点共享 AI。一次成功生成：

- **简洁**：重点明确，词数较少。
- **详细**：细节、镜头和氛围更完整，默认选中。
- **实验性**：更大胆的视觉关系和风格组合。

“简洁 / 详细 / 实验性”选择器只有在成功生成多版本后才显示。三个版本分别保存自己的编辑状态。

## 双语彩色词块

中英文区域中的同一概念共享一个词块 ID：

- 单击选择。
- 双击或按 Enter 编辑。
- 选中后按 Delete/Backspace 删除整个双语词块。
- 编辑时 Delete/Backspace 只删除字符。
- Enter 保存，Esc 取消。
- 在末尾输入并按 Enter 或逗号创建自定义词块。

中文词块修改后会防抖并只翻译这一块。直接修改英文后，该词块会显示手动保护；后续中文变化不会覆盖它，直到选择“按中文重译”。

所有复制、收藏、导出和文本推送都从当前词块重新组合。

## 结构化词块与常用词

每个词块属于主体、动作、环境、构图、镜头、光线、色彩、材质、媒介、风格、氛围、排除内容或自定义补充分组。

- 用拖动手柄进行组内排序或跨组移动。
- 把默认词或个人常用词拖到任意分组；这是复制，不会删除词库项。
- 点击词库项会放入它的默认分组。
- 默认词库只读；“我的常用词”可以新增、编辑、排序和删除。
- 常用词的“排序”数字越小越靠前，最小为 0。

## 场景模板

内置人像摄影、产品广告、电商主图、动漫角色、电影分镜、建筑空间、游戏概念图、Logo/图标、社交媒体封面和无缝纹理。

套用模板时可以：

- **合并**：保留现有词块并加入模板内容。
- **覆盖**：用模板替换当前结构。

建议在已有重要内容时使用合并。

## 参数面板

先选择：

1. 入口：Midjourney Web 或 Discord。
2. 任务：图像或视频。
3. 模型版本。

参数面板会按这三个上下文重新判断兼容性：

- 不支持的参数会置灰且无法输入；
- 已存在但变得不兼容的值不会进入完整 Prompt；
- 帮助按钮显示作用、范围、默认值、模型说明、冲突和官方链接；
- 数字参数可用减号/加号或直接输入；
- 画面比例分别输入宽和高；
- 排除内容与结构化“排除内容”词块双向同步，完整 Prompt 只输出一个 `--no`；
- Profile / Moodboard 使用可编辑代码词块。

完整 Prompt 始终按“图片 URL + 英文正文 + 规范化参数”顺序生成，参数只出现在末尾。

## 图片引用与指令助手

只支持 HTTPS 图片 URL，不上传本地文件，也不由服务器抓取图片。

- **普通图片**：放在正文前。
- **Style Reference**：支持图片 URL、数字代码或 `random`。
- **Omni Reference**：按支持模型输出。
- **视频起始/结束帧**：只在视频任务中使用。

助手说明：

- **Imagine**：生成 Web Prompt 和 Discord `/imagine prompt:` 文本。
- **Describe**：复制 `/describe`；必须在 Midjourney 中手动上传附件。
- **Blend**：校验 2–5 张图片；Discord 仍需上传文件。
- **Video**：要求起始帧，并限制到视频兼容参数。

这些助手只准备文本和操作提示，不连接官方 Midjourney 任务接口。

## 复制与导出

- **复制完整 Prompt**：正文、引用和参数。
- **只复制英文正文**：不含参数。
- **复制中文描述**：适合归档和沟通。
- **TXT / Markdown / JSON**：导出当前 Prompt、指定作品、选中作品或整个文件夹。

JSON 保留词块、参数、引用和快照版本，适合再次导入或程序处理。

## 历史和作品库

### 历史

- 成功生成后自动保存。
- 相同内容按哈希去重并更新时间。
- 每个用户只保留最新 100 条。
- 支持单条删除和批量删除。

### 作品库

- 收藏数量没有上限。
- 可设置标题、备注和文件夹。
- 删除文件夹只把作品移到“未分类”，不会删除作品。
- 保存 Prompt 内容变化会创建不可变修订；修改标题、备注或文件夹不会创建内容修订。
- 旧修订可以查看、恢复到编辑器或另存为新修订。
- 支持单条和批量删除。

历史淘汰或删除不会影响已收藏作品。

## 服务配置

每个配置模块都带步骤、字段说明、示例和官方链接。推荐流程：

1. 创建配置。
2. 保存。
3. 测试连通性。
4. 启用。
5. 回到生成区验证一次真实调用。

用户自己的配置优先于站点共享服务。完整配置方法见[配置手册](configuration.md)。

## 文本推送

“发送到配置入口”会把当前选中版本的完整 Prompt 发送到已启用的 Discord Webhook 或自定义 HTTP 端点，并记录投递状态。

Discord Webhook 发送的是普通消息，**不会因为文本含 `/imagine` 就触发 Midjourney 出图**。
