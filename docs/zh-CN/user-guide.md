# 使用指南

应用启动后直接进入“本地工作区”，无需登录。

## 编排提示词

1. 选择模板或填写主体、动作、环境、构图、镜头、光线、色彩、材质、媒介、风格、情绪和负面内容。
2. 配置画幅、版本、风格化等 Midjourney 参数。
3. 使用结构规则生成，或在服务配置中启用 AI 服务。
4. 复制或导出中英文结果。

## 本地数据

- 历史记录按内容去重，最多保留最近 100 条。
- 收藏支持标题、文件夹、修改与修订记录。
- 常用词可添加到对应字段并排序。
- 服务配置与凭据只写入本机 SQLite。

## 服务配置

在右上角打开“服务配置”，分别添加 AI、翻译和文本推送配置。保存前可测试连接；同类配置只启用一个。应用不再提供站点共享服务。

## 更新与迁移

更新客户端前关闭应用并备份 `prompt-craft.db` 与 `local.key`。新版本首次启动自动执行向前迁移。不要用另一个版本同时打开同一数据目录。

## 隐私

本地编辑和结构规则生成不会主动联网。使用第三方 AI、翻译或推送时，相应内容会发送到用户配置的服务，请遵守该服务的隐私政策。
